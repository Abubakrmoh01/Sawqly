# سوقلى Sawqly — Marketing Agency Website

موقع تعريفي (Landing / One-pager) عربي كامل بواجهة RTL لوكالة التسويق **سوقلى — Sawqly Marketing Agency**
(الشرقية، مصر). الهدف: تقديم خدمات الوكالة بشكل احترافي، وبناء الثقة، وتحويل الزائر لعملاء محتملين
عبر التواصل على فيسبوك / ماسنجر.

> الشعار والهوية البصرية (أسود + أحمر متدرّج) مأخوذة من الشعار ومن تصاميم الوكالة الأصلية.

| البند | القيمة |

لا يحتاج الموقع أي build أو npm — HTML/CSS/JS ثابت فقط. الخطوط والأيقونات من CDN:

- Font Awesome 6.4.0 من jsDelivr.

لا توجد أي مفاتيح API أو أسرار داخل الكود.

## 3. الهوية البصرية

- **اللون الأساسي:** أحمر `#e01f26` مع تدرّج إلى `#ff3b40` و`#a30d14`.
- **الخلفيات:** أبيض `#ffffff` للأقسام الفاتحة، وأسود `#0a0a0c` للأقسام الداكنة (تتبادل Ahrefs-style).
- **الكلمات المميزة:** `.hl` بتدرّج أحمر على النص (background-clip: text).
- **اللوجو في الهيدر:** يظهر علامة «S» الحمراء فقط — عبر `background-image` مع `background-size: 290%`
  و`background-position` مقصوصة على العلامة (`css/style.css`، قسم `.logo-badge`).
  الصورة الأصلية الكاملة `images/sawaly-logo.png` مستخدمة كما هي في فوتر الموقع.

## 4. التفاعلات (js/main.js)

1. **هيدر ثابت** يتحول لحالة مضغوطة بعد 24px scroll + إظهار زر «للأعلى».
2. **منيو موبايل off-canvas** (≤980px) — يُغلق بالضغط على رابط، أو Escape، أو تغيير المقاس.
   مخفي بـ `opacity/visibility` لا بـ `translateX` خارج الشاشة، لتجنّب أي overflow أفقي.
3. **IntersectionObserver**:
   - كشف شرائح `.reveal` بحركة ظهور متتابعة (+ شبكة أمان بعد 900ms).
   - عدّادات الأرقام في `.stat-num` (4 / 6 / 12 / 100%).
   - تظليل رابط القسم النشط في القائمة.
4. **أكورديون الأسئلة الشائعة** — عنصر واحد مفتوح في المرة، مع `aria-expanded`.
5. **Lightbox للمعرض** — فتح/إغلاق بالنقر خارج الصورة أو Escape، إرجاع التركيز للزر.
6. **نموذج التواصل** — تحقق بسيط من الاسم والرسالة، ثم:
   - ينسخ نص الرسالة المجهّز إلى الحافظة (Clipboard API إن كان متاحاً).
   - يفتح `https://m.me/61595443958005` في تاب جديد لإرسالها.
   - **لا يتم تخزين أي بيانات ولا إرسالها لأي سيرفر** — لا توجد قاعدة بيانات.
7. **احترام `prefers-reduced-motion`** — تعطيل الحركات والعدّادات.

## 5. الاستجابة (Breakpoints)

| العرض | التغييرات |
|---|---|
| > 1080px | شبكة الهيرو عمودان، الأقسام بعمودين+ |
| ≤ 1080px | الهيرو عمود واحد، صورة مركزية، «مين سوقلى» والتواصل بعمود واحد |
| ≤ 980px | منيو off-canvas + هامبرغر، معرض بعمود واحد |
| ≤ 640px | عناوين أصغر، أزرار الهيرو بعرض كامل، حقول الفورم صف واحد، فوتر بعمودين |
| ≤ 400px | شريط الأرقام 2×2 |

تم التحقق بصرياً على **1280px (ديسكتوب)** و**390px (موبايل iPhone)** — لا يوجد overflow أفقي،
ولا نص مقطوع. الكونسول نظيف (لا أخطاء JS).

## 6. SEO / الوصولية

- `title` و`meta description` و`keywords` وOpen Graph (بـ `ar_EG`) و`theme-color`.
- JSON-LD من نوع `ProfessionalService` يحتوي الاسم، الشعار النصي، المنطقة، ورابط فيسبوك.
- HTML دلالي: `header/nav/main/section/article/figure/footer`، عناوين متدرّجة، `alt` لكل صورة.
- `skip-link`، `:focus-visible` واضح، `aria-expanded` / `aria-controls` / `aria-live` للفورم
  والأكورديون، `aria-label` للأزرار الأيقونية.
